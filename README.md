# Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## About the Project

This project is a browser-based implementation of the classic Tic-Tac-Toe game. Players take turns marking cells on a 3 × 3 grid.

## Features

* Interactive game board
* Two-player gameplay
* Option to restart the game

## Technologies Used

* HTML
* CSS
* JavaScript

## What I Learned

* JavaScript event handling
* Conditional statements and functions
* Basic game logic
